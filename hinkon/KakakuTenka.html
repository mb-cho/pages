価格転嫁の重層構造と企業の過去最高益

インフレ会計の錯視、円安による海外配当・営業外収益の統計バイアス、そして下請け労務費買い叩き――企業の過去最高益（124.8兆円）と労働分配率急落（63.0%）の真実を解剖する

💡 本稿の要約（エグゼクティブ・サマリー）

2021〜2025年度にかけて、日本企業の経常利益は124.8兆円という前人未到の過去最高記録を更新しました。これに伴い、春闘では2024年（5.10%）、2025年（5.25%）、2026年（連合方針5%以上・実績5.01%）と「3年連続5%超の歴史的賃上げ」が華々しく喧伝されています。

しかし、マクロ経済の現場では、全産業の労働分配率が「63.0%」という約半世紀ぶりの歴史的低水準へ崖下り急落し、実質賃金は2022年4月から2024年5月にかけて過去最長となる「26ヶ月連続マイナス」を記録しました。

「原材料高を転嫁しただけなら利益はトントンのはず」「増益はすべて国内での搾取によるもの」という単純な見方は、現代の多角的な企業会計と国際マクロ構造を見落としています。企業の最高益と労働分配率急落の背景には、以下の4つの重層的メカニズムが複合的に作用しています。

⚖️ ① インフレ会計の錯視（定率転嫁）

従来のマークアップ率（粗利率）を維持して価格転嫁を行う「定率転嫁」では、実質的な利幅を広げずとも名目利益額がインフレ率に応じて自然増します。

🌏 ② 海外収益と統計バイアス

経常利益124.8兆円の主因は円安に伴う「海外子会社からの受取配当金等」の膨張です。これは国内付加価値（分母）を増やしますが、海外人件費は国内分子に入らないため、統計上分配率が押し下げられます。

📈 ③ 国内マークアップ拡大と便乗値上げ

デフレ脱却ムードに乗じた川下大企業の「実質マークアップ率引き上げ（グリードフレーション）」が、売上高増加率＞原価増加率をもたらし利益率を高めました。

🏢 ④ 下請け労務費買い叩きと企業の二極化

下請けへの労務費転嫁率はわずか3〜4割にとどまります。春闘5%の恩恵を受けるグローバル大企業と、分配率が70〜80%台で高止まりし賃上げ余力のない内需中小企業が決定的に分断されています。

🔍 01. 疑問の出発点：インフレ会計の錯視と「定額転嫁」vs「定率転嫁」

企業の損益計算書（P/L）において、本業の営業利益 $\Pi_{op}$ は以下の会計恒等式で表されます。

$$\Pi_{op} = S - C_{in} - W$$
$S$：売上高（販売数量 $Q \times$ 製品価格 $P$）
$C_{in}$：中間投入コスト（原材料費、燃料・エネルギー費、外注加工費等）
$W$：人件費（基本給、賞与、諸手当、法定福利費等）

いま、ウクライナ危機や為替変動により、中間投入コストが $\Delta C_{in} > 0$ だけ高騰したとします。このとき、企業が製品価格にコスト上昇を反映させる「価格転嫁」には、実務上**2つの異なる価格設定行動**が存在します。

① 定額転嫁（同額転嫁モデル）

原材料コストの上昇額と「同額（1対1）」だけ製品価格を引き上げる手法です。

$$\Delta S = \Delta C_{in} \implies \Delta \Pi_{op} = 0$$ 原価が10円上がったので価格を10円だけ値上げした場合、売上増と原価増が完全に相殺され、人件費 $W$ が不変なら利益額は1円も増えず横ばい（トントン）にとどまります。

② 定率転嫁（マージン率維持モデル）

従来の粗利益率（マークアップ率 $\mu$）を「一定比率」で維持するように価格を設定する手法です（実務で広く採用）。

$$S = (1 + \mu) C_{in} \implies \Delta S = (1 + \mu) \Delta C_{in}$$ 例えば原価80円・売価100円（粗利20円・利益率20%）の商品で原価が20%上がって96円になった際、利益率20%を維持して売価を120円に改定すると、名目利益額は20円から24円へと20%自動的に自然増します。
💡 会計学的なポイント：
インフレ下においては、実質的な利幅を拡大する「便乗値上げ」を行わなくても、従来の利益率を維持する「定率転嫁」を行うだけで、名目上の利益額（円建ての金額）はインフレ率に比例して自然に膨張します。「コストを転嫁しただけなら利益は絶対に横ばいになるはずだ」という直観は、定額転嫁のみを前提とした初歩的な会計的錯視です。

しかし、ここで真の経済的疑問が生じます。もし企業行動が単なる「定率転嫁」であったなら、インフレ率と同率で労働者の基本給（ベースアップ）が引き上げられれば、労働分配率は安定的に維持されるはずです。

なぜ現実の日本企業は、名目利益が自然増するにとどまらず、経常利益124.8兆円という歴史的最高記録を大幅に更新し、同時に労働分配率が63.0%という半世紀ぶりの低水準へ崖下り急落したのでしょうか？ そこには、単なるインフレ会計を超えた3つの決定的な構造要因が存在します。

🌏 02. 要因①：マクロ会計の現実――「経常利益」の海外配当膨張と統計的バイアス

第1の要因は、財務省『法人企業統計』が示す「124.8兆円」という数字自体の会計的性質です。この数字は国内事業の「営業利益」ではなく、**「経常利益（全産業・金融保険除く）」**です。

$$\text{経常利益 } \Pi_{ord} = \text{営業利益 } \Pi_{op} + \text{営業外収益（受取配当金・為替差益等）} - \text{営業外費用}$$

① 円安による海外子会社からの「受取配当金」と為替差益の激増

2021年の1ドル＝110円前後から、2024〜2025年には1ドル＝155〜160円台へと歴史的な円安が進行しました。日本を代表するグローバル製造業や総合商社は、過去20年間にわたり生産拠点の海外移転を進めてきました。

その結果、海外子会社が現地で稼ぎ出したドル建ての利益や配当金が、円安によって円換算で自動的に天文学的な規模へと膨れ上がりました。経済産業省や日銀の国際収支統計を見ても、第一次所得収支（海外からの利子・配当）は年間**35兆〜40兆円規模**という過去最高水準に達しています。この海外からの巨額配当の還流こそが、法人企業統計の「経常利益124.8兆円」を押し上げた最大のエンジンです。

② 【決定的盲点】多国籍企業化による「労働分配率の統計的押し下げバイアス」

さらに重要なのが、法人企業統計における労働分配率の構造的歪み（統計的バイアス）です。

⚠️ 労働分配率の多国籍化バイアス（分母と分子の非対称性）：
財務省の定義において、付加価値額（分母）には海外子会社からの受取配当金を含む営業純益が算入されます。しかし、その海外現地法人で実際に働いている現地従業員の人件費は、日本の国内統計における人件費（分子）には一切計上されません。
したがって、日本企業がグローバル展開を加速させ、円安によって海外からの配当が膨らむほど、「分子（国内人件費）は増えないのに分母（付加価値額）だけが肥大化する」ため、国内マクロの労働分配率は算術的・機械的に急低下してしまうのです。

つまり、労働分配率63.0%への低下の一部は、国内労働者への締め付けだけでなく、**「日本企業の収益構造が海外多国籍化し、円安で海外利益の円換算が跳ね上がったことによる統計構造上の結果」**という側面を冷静に見極める必要があります。

📈 03. 要因②：国内価格転嫁における「実質マークアップ率の拡大（便乗値上げ）」

海外要因だけでなく、国内の商取引においても明確な変化が生じました。それが、単なる定率転嫁（マージン維持）を超えた**「実質マークアップ率の引き上げ（グリードフレーション）」**です。

30年間続いたデフレ経済下では、企業は「わずかでも値上げすれば客が離れる」という強烈な恐怖に縛られていました。しかし、2022年以降の世界的な原材料高と円安により、日本社会全体に「30年ぶりのインフレ容認ムード」が形成されました。

  • A
    便乗値上げによる利ざや拡大

    価格改定への抵抗感が薄れた機を捉え、川下大手企業（食品、流通、外食、日用品、耐久消費財など）は、単に「原材料コストの上昇分10円」を転嫁するだけでなく、将来のインフレ予測や追加利益を織り込んだ**「15円〜20円の値上げ」**を実施しました。

  • B
    公的データが実証する原価率の低下

    内閣府『年次経済財政報告』および日本銀行のワーキングペーパー（青木浩介・法眼吉彦ら）の実証分析によると、2022〜2024年の日本企業では**「売上高の増加率が仕入原価の増加率を一貫して上回り、売上高原価率が低下（マークアップ率が上昇）」**したことが確認されています。

欧州中央銀行（ECB）やIMFが欧米市場で指摘した「ユニット・プロフィット（単位当たり企業利潤）の拡大によるインフレ押し上げ」現象が、日本国内の川下市場でも確実に現出したのです。

⚖️ 04. 要因③：産業構造の非対称性――消費者には転嫁し、下請け労務費は叩く

最高益と生活困窮が併存する最も深刻な国内要因が、サプライチェーンにおける**「二重基準（非対称な価格転嫁）」**です。

川下（対消費者・一般市場）

積極的かつ強気の価格転嫁（転嫁率100%〜120%）

エネルギー高や円安を正当な理由として値上げを連発。ブランド力と市場支配力を持つ大企業は、マージンを上乗せして粗利益を大幅に拡大させました。

川上（対下請け中小企業）

労務費（賃上げ原資）の転嫁拒絶（転嫁率35%前後）

下請け企業から「電気代や鉄鋼代だけでなく、従業員の生活を守る賃上げ分も単価に乗せてほしい」と要請されても、優越的地位を背景に徹底して据え置きました。

📊 公正取引委員会・中小企業庁の調査事実：
政府の「価格交渉促進月間フォローアップ調査」によれば、原材料費の転嫁率は60〜70%程度まで進展したものの、**「労務費（人件費上昇分）の転嫁率」はわずか3割台（約35%）**にとどまっています。下請け企業の約6割が、賃上げ原資を単価に反映できず自社の身を削って吸収することを強いられました。

発注元の大企業は「自社の売値はインフレで吊り上げ、下請けへの外注費（労務費）は買い叩いて抑え込む」ことで、その**スプレッド（利ざや）を自社の経常利益として独占**したのです。

📉 05. 要因④：企業の二極化と「春闘5%」の虚実

メディアでは「2024年5.10%、2025年5.25%、2026年実績5.01%」と、3年連続の5%超賃上げが熱狂的に報じられました。しかし、この数字とマクロ経済の困窮の間には**3つの重大なギャップ**が存在します。

  • 1
    春闘（大企業中心）とマクロ統計（中小企業含む）の決定的分断

    連合の春闘集計は、組織化された大手企業の労働組合が中心です。 過去最高益に沸く大手輸出企業や金融・商社が5〜6%台の賃上げを実施する一方で、日本で働く労働者の約7割を雇用する中小企業は、下請け労務費の転嫁拒絶によって利益が激減していました。 中小企業では労働分配率がすでに**70〜80%台と高止まり**しており、これ以上賃金を上げれば赤字転落・倒産する瀬戸際に追い込まれています。「利益が丸残りしているグローバル大企業」と「原資が尽きた内需型中小企業」という**強烈なK字型の二極化**が生じたのです。

  • 2
    定期昇給（定昇）とベースアップ（ベア）の分離

    「5.10%」の賃上げのうち、約1.8%は年齢上昇に伴う自然増である「定期昇給」であり、全社員の賃金ベースを一律に引き上げる**純粋な「ベースアップ（ベア）」は3.3%前後**でした。インフレ率が3〜4%で推移する局面において、実質的な生活向上をもたらすには力不足でした。

  • 3
    実質賃金26ヶ月連続マイナスの時間軸の正確な検証

    厚生労働省『毎月勤労統計調査』における「実質賃金26ヶ月連続マイナス（2022年4月〜2024年5月）」は、急激な輸入インフレの初動に対し、企業の賃金改定が遅れた「タイムラグ」の産物です。 2024年後半以降、春闘の妥結が給与に反映され始めて名目賃金は伸びたものの、中小企業への波及が鈍く、物価高の累積ダメージを相殺するには至っていません。

📐 06. 数理的検証：控除法・加算法と労働分配率の統合方程式

以上の要因を、マクロ経済学と財務省の企業統計定義に基づき数理モデルとして統合します。

$$\text{労働分配率 } LS = \frac{\text{国内人件費 } W}{\text{付加価値額 } VA}$$
【控除法（生産・取引側）】 $VA = \text{売上高}(S) - \text{中間投入コスト}(C_{in})$
【加算法（配分・決算側：財務省定義）】 $VA = \text{人件費}(W) + \text{営業純益}(\Pi_{net}) + \text{動産・不動産賃借料}(R) + \text{租税公課}(T) + \text{支払利息等}(I)$
※財務省定義：$\text{営業純益 } \Pi_{net} = \text{営業利益} - \text{支払利息等}$。さらに経常利益には海外配当等の営業外収益 $\Pi_{foreign}$ が加わる。
$$LS = \frac{W}{S - C_{in}} = \frac{W}{W + \Pi_{net} + R + T + I} = \frac{1}{1 + \frac{\Pi_{net} + R + T + I}{W}}$$
【数理的帰結の総括】：
  1. 国内要因：実質マークアップ拡大（$\Delta S > \Delta C_{in}$）と下請け労務費抑制により国内付加価値が膨張。自社ベア抑制（$\Delta W$ 微増）により、利潤倍率 $\frac{\Pi_{net}}{W}$ が急騰。
  2. 国際・統計要因：円安による海外配当 $\Pi_{foreign}$ の激増が分母の付加価値をさらに押し上げる一方、海外人件費は分子 $W$ に入らない（多国籍化バイアス）。
  3. この内外両面からの分母拡大と分子抑制が同時に作用した結果、労働分配率 $LS$ は必然的・算術的に「63.0%」へと急落した。

📊 08. 本来あるべき好循環 vs 日本の二極化構造の現実
